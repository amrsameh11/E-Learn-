Epic 1: User Management
Goal: Help users create accounts and manage their profiles.

User stories under this epic:

 As a user, I want to create an account, so that I can use the platform.
 As a user, I want to log in to my account, so that I can access my courses.
 As a user, I want to update my profile, so that my information stays correct.
 ----------------------------------------------------------------------------------------------
 Epic 2: Course Management
 Goal: Help students find courses and instructors manage them.

User stories under this epic:

 As a student, I want to browse available courses, so that I can find courses that interest me.
 As a student, I want to view course details, so that I can decide which course to take.
 As an instructor, I want to create and update courses, so that I can share my knowledge.
 ----------------------------------------------------------------------------------------------
Epic 3: Learning and Progress Tracking
Goal: Help students learn new skills and track their progress.

User stories under this epic:

 As a student, I want to view lessons, so that I can learn new skills.
 As a student, I want to take quizzes, so that I can test my knowledge.
 As a student, I want to track my progress, so that I can know how much I have learned.
 ----------------------------------------------------------------------------------------------
Epic 4: Communication and Feedback
Goal: Help students and instructors communicate and share feedback.

User stories under this epic:

 As a student, I want to rate and review courses, so that I can share my opinion.
 As a student, I want to ask questions, so that I can understand lessons better.
 As an instructor, I want to send announcements, so that I can inform students about updates.
 ----------------------------------------------------------------------------------------------
Epic 5: Administration and Reports
Goal: Help administrators manage the platform and monitor its performance.

User stories under this epic:

 As an administrator, I want to manage users, so that I can control access to the platform.
 As an administrator, I want to view platform statistics, so that I can monitor its performance.
 As an administrator, I want to manage course content, so that the platform stays organized.
