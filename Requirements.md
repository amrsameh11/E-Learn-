 Functional Requirements:**
- Users can create accounts and log in.
- Users can view courses and lessons.
- Instructors can add and manage courses.
- Users can take quizzes and track their progress.

 Non-Functional Requirements:**
- The system should be easy to use.
- The system should protect user data.
- The system should respond quickly.
- The system should be available at all times.

 User Interface Requirements:**
- The system should have a simple and clear design.
- The system should work on computers and mobile phones.
- The system should have easy navigation between pages.
- The system should display courses and lessons clearly.
