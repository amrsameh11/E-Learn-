### Functional Requirements

1. Students can create accounts and log in.
2. Students can enter their skills and previously completed courses.
3. The system recommends suitable courses using Machine Learning.
4. Students can view course details, prices, duration, and session schedules.
5. Students can book courses and pay online.
6. Students can attend live sessions with instructors.
7. The system records sessions and makes recordings available to enrolled students at any time.
8. Students can watch recorded sessions whenever they want.
9. Instructors can register and upload their certificates and qualifications.
10. Instructors can add courses, skills, and session details.
11. Instructors can schedule live sessions and manage recordings.
12. Admins can review instructor certificates and submitted information.
13. Admins can approve or reject instructors and their courses.
14. The system displays approval status to instructors.
15. Admins can manage users and monitor courses and payments.
16. Only students enrolled in a course can access its live sessions and recordings.



 ### Non-Functional Requirements

1. The system should be easy to use.
2. The system should protect user information and uploaded certificates.
3. The system should respond quickly when displaying recommendations.
4. The system should provide relevant course recommendations.
5. The system should be available whenever users need it.
6. The system should handle multiple users at the same time.
7. The payment process should be secure.
8. The system should allow future improvements to the Machine Learning model.
9. Live sessions should provide stable audio and video quality.
10. Recorded sessions should load quickly and be available whenever needed.
11. Session recordings should be stored securely and protected from unauthorized access.
12. The system should support multiple students attending live sessions simultaneously.



### User Interface Requirements

1. The student interface should allow users to enter their skills and previous courses.
2. The system should display recommended courses clearly.
3. Each course page should show its price, duration, and number of sessions.
4. Students should be able to join live sessions with instructors.
5. Students should be able to watch recorded sessions at any time.
6. The course page should display live session schedules and available recordings.
7. The instructor interface should allow uploading certificates, adding courses, scheduling sessions, and managing recordings.
8. The admin dashboard should display submitted documents and approval statuses.
9. The interface should be simple and work on computers and mobile phones.
